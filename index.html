Restricted Storage Architecture & NFS Buses

Multi-tier storage topology on node-33 with strict access controls separating high-performance flash from archival storage.

Fast Tier: 1 TB CMR Landing HIGH IOPS

High-speed CMR storage layer serving as the primary Proxmox vzdump landing zone and hosting high-throughput append-only Rustic REST repositories.

• Subnet-wide access for rapid disaster recovery dumps
• Immune to SMR write-cliff degradation during parallel backups
Cold Tier: 8 TB Archival Pool RESTRICTED NFS

High-capacity archival storage strictly isolated to authorized clients. Powers media libraries and immutable snapshot archives.

• Media export restricted read-only with UID squashing
• Immich photo data isolated over dedicated NFS v3 links
Proxmox NVMe Flash Storage DATABASE TIER

Local solid-state NVMe storage on proxmox nodes backing database containers, Redis caches, and Qdrant vector memory.

• Sub-millisecond random access for relational queries
• Local ZFS datasets for high-density container disks
